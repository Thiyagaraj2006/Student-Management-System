# Student-Management-System
The Student Management System is a database-driven application designed to manage student information efficiently. The project performs CRUD (Create, Read, Update, Delete) operations using Python and MySQL. It helps in maintaining student records in an organized and secure manner.
## Technologies Used
Python
MySQL
mysql-connector-python
## Features
Add Student Records
View Student Details
Search Student by ID
Update Student Information
Delete Student Records
MySQL Database Connectivity
Console-Based User Interface

CRUD Operations
